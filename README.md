# Team04_A4_Source

Dependencies: Node.js

How to open the website:
- In a terminal, navigate to the folder containing `package.json`
- Run the command `npm install` to install the dependencies
- Run the command `node server.js` to start the server
- Open the link printed in the terminal

If you do not have node and do not want to install it, you can also copy the array inside `items.json` and replace the return inside `search.js::getItems()` with `await [etc etc etc]`. The website should work the same (and pretend a server is serving the files).\
